# EvidenceLab: RAG vs GraphRAG vs Agentic GraphRAG

Ask one question to three pipelines (RAG, GraphRAG, Agentic GraphRAG) that share one Gemini model and one TigerGraph Savanna graph (TigerVector, TigerGraph MCP server). The other tabs show the saved evaluation on the public questions: accuracy, tokens, latency and which question types need an agent.
